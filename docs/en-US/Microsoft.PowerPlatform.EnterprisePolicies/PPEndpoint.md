# PPEndpoint

## DESCRIPTION

Represents the different PP endpoints that can be used to connect to Power Platform services. Only endpoints that are currently supported are included.

## PROPERTIES

| Enum Value Name | Description |
|-----------------|-------------|
| unknown | No option selected. |
| tip1 | Microsoft internal use only. |
| tip2 | Microsoft internal use only. |
| prod | Azure Public cloud endpoint, cmdlets will default to this value. |
| usgovhigh | Azure Government Community Cloud High endpoint. |
| dod | Azure Department of Defense endpoint. |
| china | Azure China cloud endpoint. |
| custom | Externally configured endpoint. Set `PP_ENTERPRISE_POLICIES_ENDPOINTS` to a JSON object containing absolute HTTPS URLs for `Authority`, `Bap`, `PowerApps`, and `Api`, plus a boolean `IsSingleCharEndpoint` route-partition setting. |

### EXAMPLE 1

```powershell
$endpoint = [PPEndpoint]::prod
```
