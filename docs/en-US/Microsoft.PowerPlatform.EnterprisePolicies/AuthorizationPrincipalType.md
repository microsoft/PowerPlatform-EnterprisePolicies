# AuthorizationPrincipalType

## DESCRIPTION

Represents the type of Microsoft Entra ID principal that a Power Platform RBAC operation targets. The value is supplied through the `-PrincipalType` parameter of New-PPRBACRoleAssignment, Get-PPRBACRoleAssignment, and Test-PPRBACDiagnosticPermission.

## PROPERTIES

| Enum Value Name | Description |
|-----------------|-------------|
| User | An individual user principal identified by its object ID. |
| Group | A security group principal identified by its object ID. |
| ApplicationUser | An application (service principal) principal identified by its object ID. |

## EXAMPLES

### EXAMPLE 1

```powershell
$principalType = [AuthorizationPrincipalType]::User
```
